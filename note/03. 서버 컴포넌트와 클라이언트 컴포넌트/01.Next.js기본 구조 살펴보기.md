# Next.js 프로젝트 구조 정리

`create-next-app`으로 생성한 Next.js 초기 프로젝트의 폴더 및 파일 구조 설명입니다.

## 📁 폴더

### `.next`

- 빌드 결과물과 캐시가 저장되는 폴더
- `npm run build` 또는 `npm run dev` 실행 시 자동 생성
- 개발자가 직접 수정하지 않음

### `node_modules`

- 설치된 모든 npm 패키지가 들어있는 폴더
- react, next, react-dom, eslint, Tailwind CSS 등 프로젝트 의존성 설치 위치
- 개발자가 직접 수정하지 않음

### `public`

- 정적 파일을 보관하는 폴더
- 이미지, 아이콘, 폰트 등 빌드 시 별도 가공 없이 그대로 제공할 리소스 저장

### `src` / `app`

- 앱 라우터 기반 라우팅 구조의 핵심 폴더
- `src` 폴더: 소스코드 전용 폴더
- `app` 폴더: 라우트 단위 폴더 역할
- Next.js 시스템에서 정해진 폴더 이름이므로 **임의로 변경 불가**

## 📄 주요 파일

| 파일명               | 설명                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------- |
| `layout.tsx`         | 모든 페이지에 공통 적용되는 레이아웃 파일 (헤더, 푸터, 내비게이션 등 공통 요소 정의)                          |
| `page.tsx`           | 라우트의 기본 페이지 컴포넌트 (예: 루트 경로 화면 → `npm run dev` 실행 시 보이는 초기 화면)                   |
| `globals.css`        | 프로젝트 전역 스타일 시트. Tailwind CSS 임포트 코드 포함. 보통 `layout.tsx`에서 한 번만 임포트                |
| `.gitignore`         | git 버전 관리에서 제외할 파일/폴더 목록 정의 (`node_modules`, `.next`, `.env` 등)                             |
| `favicon.ico`        | 브라우저 탭에 표시되는 사이트 아이콘. `app` 폴더 내부에 두면 Next.js가 자동 인식                              |
| `next-env.d.ts`      | TypeScript와 Next.js 간 타입 정의를 연결하는 자동 생성 파일. 직접 수정 불필요, **삭제 금지** (오류 발생 가능) |
| `next.config.ts`     | Next.js 설정 파일. 이미지, 도메인, 리다이렉션, 캐시 전략, 리액트 컴파일러, 터보팩 등 커스터마이징             |
| `tsconfig.json`      | TypeScript 컴파일러 설정 파일. 경로 별칭, 스트릭트 모드, JS 설정 등 포함                                      |
| `postcss.config.mjs` | Tailwind CSS, Auto Prefixer 등 CSS 빌드 도구 설정 파일. CSS 처리 파이프라인 정의                              |
| `package.json`       | 프로젝트 메타데이터 및 의존성 버전 관리. `scripts` 영역에 실행 가능한 명령어 정의                             |
| `package-lock.json`  | 설치된 의존성의 정확한 버전 정보 관리                                                                         |
| `README.md`          | 프로젝트 설명 파일. GitHub 등에서 자동 렌더링되어 소개 및 실행 방법 안내                                      |

## 요약

Next.js는 여러 폴더와 파일들이 자동으로 기본 생성되어 하나의 프로젝트를 구성합니다.
