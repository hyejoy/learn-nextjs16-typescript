# 서버 컴포넌트에서 headers, cookies 읽기

클라이언트 컴포넌트는 기존 React 컴포넌트와 거의 동일해서 새롭게 배울 것이 많지 않지만, **서버 컴포넌트는 실행 환경과 역할이 다르기 때문**에 서버에서만 가능한 작업들을 다룰 수 있습니다. 대표적인 예가 **요청 헤더(headers)**와 **쿠키(cookies)** 조회입니다.

## 요청 헤더 (headers)

### 개념

- 브라우저가 서버로 요청을 보낼 때 함께 전달하는 **HTTP 요청 헤더**
- 예: 사용 중인 브라우저, 운영체제, 선호 언어 등의 정보

### 사용법

```tsx
import { headers } from "next/headers";

export default async function Page() {
  const headerList = await headers();
  const userAgent = headerList.get("user-agent");

  return <div>{userAgent}</div>;
}
```

- `headers()` 함수는 `next/headers` 패키지에서 import
- 호출 결과로 헤더 정보를 담은 객체 반환
- `get()` 메서드로 특정 헤더 값 조회

### 주요 헤더 예시

| 헤더         | 설명                            |
| ------------ | ------------------------------- |
| `user-agent` | 접속에 사용한 브라우저, OS 정보 |
| `host`       | 요청 대상 호스트 정보           |

- 그 외 사용 가능한 헤더 종류는 MDN의 **HTTP Request and Response Headers** 문서에서 확인 가능 (`get` 메서드에 마우스를 올리면 링크 확인 가능)

## 쿠키 (cookies)

### httpOnly 쿠키 테스트 준비

1. 개발자 도구 → Application 탭
2. `Clear site data`로 기존 쿠키 초기화
3. `localhost:3000` 쿠키 항목에 값 추가
   - name: `name`
   - value: `김`
   - `httpOnly`: `true` 체크

### httpOnly 쿠키의 특징

- 일반 쿠키는 클라이언트 컴포넌트에서도 읽기 가능
- **`httpOnly: true`인 쿠키는 클라이언트에서 읽을 수 없음** → 오직 서버에서만 읽기 가능
- 서버 컴포넌트는 서버에서만 실행되므로 httpOnly 쿠키도 읽을 수 있음

### 사용법 - 특정 쿠키 하나 읽기

```tsx
import { cookies } from "next/headers";

export default async function Page() {
  const cookieStore = await cookies();
  const nameCookie = cookieStore.get("name");

  console.log(nameCookie);
  // { name: 'name', value: '김' }

  return <div>{nameCookie?.value}</div>;
}
```

- `cookies()` 함수도 `next/headers`에서 import
- `get()` 메서드로 특정 이름의 쿠키 조회 → `{ name, value }` 형태의 객체 반환
- 쿠키가 없을 수도 있으므로 **옵셔널 체이닝(`?.`)** 사용 권장 (타입 에러 방지)

### 사용법 - 모든 쿠키 한 번에 읽기

```tsx
import { cookies } from "next/headers";

export default async function Page() {
  const cookieStore = await cookies();

  return cookieStore.getAll().map((cookie) => (
    <div key={cookie.name}>
      {cookie.name}: {cookie.value}
    </div>
  ));
}
```

- `getAll()` 메서드로 모든 쿠키를 배열로 반환
- `map()`으로 반복 렌더링

## 정리

- 서버 컴포넌트는 **요청 헤더와 쿠키를 읽어와 로직을 구성**하는 데 활용 가능
- 특히 `httpOnly` 쿠키처럼 클라이언트에서 접근 불가능한 데이터도 서버 컴포넌트에서는 읽을 수 있음
- 향후 **인증 처리, 사용자 구분, 요청 환경별 분기 처리** 등을 구현할 때 핵심적으로 쓰이는 기능이므로 반드시 기억해둘 것
