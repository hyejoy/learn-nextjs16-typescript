# 라우트 전환 (Link 컴포넌트)

## 라우트를 전환하는 방법

Next.js App Router에서 페이지 간 이동(라우트 전환)을 하는 방법은 여러 가지가 있습니다.

1. **브라우저 주소창에 직접 URL 입력** — 가장 단순하지만 실제 서비스에서는 잘 쓰이지 않는 방법
2. **페이지 내에서 클릭으로 자연스럽게 이동** — 실무에서 사용하는 방식

## HTML `<a>` 태그 vs Next.js `<Link>` 컴포넌트

Next.js에서는 `<a>` 태그 대신 **`Link` 컴포넌트**를 사용합니다.

```tsx
import Link from "next/link";

export default function Page() {
  return <Link href="/about">About</Link>;
}
```

- `next/link` 패키지에서 import
- `<a>` 태그처럼 `href` 속성에 이동할 경로를 지정
- 실제로 렌더링될 때는 **`<a>` 태그로 변환되어 렌더링**됨

### 그렇다고 `<a>` 태그와 완전히 같은 것은 아님

| 구분      | HTML `<a>` 태그                                        | Next.js `<Link>` 컴포넌트                       |
| --------- | ------------------------------------------------------ | ----------------------------------------------- |
| 전환 방식 | 페이지 전체를 새로 불러옴 (Full reload)                | 변경된 부분만 업데이트                          |
| 리소스    | 클릭할 때마다 HTML, CSS, JS 리소스를 **다시 다운로드** | 공유되는 부분은 그대로 유지, 필요한 부분만 교체 |
| 체감      | 전환 시 화면이 깜빡이며 새로고침되는 느낌              | 부드럽게(smooth) 전환됨                         |

### `<a>` 태그 사용 시

- `/about`으로 이동은 되지만, 클릭할 때마다 **전체 리소스를 다시 다운로드**
- 공통 UI 영역(헤더 등)도 함께 깜빡이며 다시 로드됨

### `<Link>` 컴포넌트 사용 시

- 라우트 전환 시 **변경된 부분만 업데이트**
- 공유되는 레이아웃/UI 영역은 **전혀 리렌더링되지 않고 그대로 유지**
- 페이지를 다시 다운로드하지 않으므로 훨씬 빠르고 부드러운 전환 경험 제공

## target 속성 사용

`Link` 컴포넌트도 HTML `<a>` 태그처럼 `target` 속성을 그대로 사용할 수 있습니다.

```tsx
<Link href="/about" target="_blank">
  About (새 탭에서 열기)
</Link>
```

- `target="_blank"` 지정 시 이동할 라우트가 **새 탭**으로 열림

## 정리

| 태그             | 전환 방식                                            |
| ---------------- | ---------------------------------------------------- |
| HTML `<a>`       | 페이지 전체를 새로 불러오는 방식 (Full Page Reload)  |
| Next.js `<Link>` | 필요한 부분만 교체하는 방식 (Client-side Transition) |

- Next.js에서는 **특별한 이유가 없는 한 `<a>` 태그 대신 `Link` 컴포넌트 사용을 권장**
- `Link` 컴포넌트는 `next/link`에서 import하며, `href`, `target` 등 HTML `<a>` 태그와 유사한 속성을 지원
