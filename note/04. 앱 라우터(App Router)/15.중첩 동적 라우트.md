# 중첩 동적 라우트 (Nested Dynamic Routes)

## 문제 상황

`/post/post1/comment/comment1`처럼 **동적으로 변경되는 세그먼트가 2개 이상** 필요한 경우를 살펴봅니다.

## 폴더 구조

동적 라우트를 **중첩**해서 정의하면 됩니다.

```
app/
 └── post/
      └── [id]/
           └── comment/
                └── [commentId]/
                     └── page.tsx
```

| 세그먼트 순서 | 폴더                 |
| ------------- | -------------------- |
| 1번째         | `post` (고정)        |
| 2번째         | `[id]` (동적)        |
| 3번째         | `comment` (고정)     |
| 4번째         | `[commentId]` (동적) |

```tsx
// app/post/[id]/comment/[commentId]/page.tsx
export default async function Page({
  params,
}: {
  params: Promise<{ id: string; commentId: string }>;
}) {
  const { id, commentId } = await params;

  return (
    <div>
      Post ID: {id} / Comment ID: {commentId}
    </div>
  );
}
```

- `/post/1/comment/1`, `/post/1/comment/2`, `/post/100/comment/100` 등 다양한 값에 모두 매칭됨

## ⚠️ 주의: 동적 세그먼트 식별자는 중복될 수 없음

같은 경로 트리 안에서 동적 세그먼트가 여러 개 있을 경우, **폴더 식별자는 반드시 서로 달라야** 합니다.

```
❌ app/post/[id]/comment/[id]/page.tsx   // 에러 발생 (id 중복)
✅ app/post/[id]/comment/[commentId]/page.tsx   // 정상
```

- 2번째 세그먼트와 4번째 세그먼트를 둘 다 `[id]`로 지정하면 **에러 발생**
- 따라서 `id`, `commentId`처럼 각기 다른 이름으로 지정해야 함

## 컴포넌트에서 동적 세그먼트 값 가져오기

### 서버 컴포넌트

```tsx
export default async function CommentDetailPage({
  params,
}: {
  params: Promise<{ id: string; commentId: string }>;
}) {
  const { id, commentId } = await params;

  return (
    <div>
      <p>id: {id}</p>
      <p>commentId: {commentId}</p>
    </div>
  );
}
```

- `params`의 타입에 필요한 동적 세그먼트 식별자를 모두 나열
- **하위 세그먼트에서는 상위 세그먼트의 동적 값도 함께 받아올 수 있음**
  - 예: `[commentId]` 폴더 하위 페이지에서도 상위 `[id]` 값을 `params`에 함께 지정하면 받아올 수 있음

### 클라이언트 컴포넌트

```tsx
"use client";

import { useParams } from "next/navigation";

export default function CommentPage() {
  const { id, commentId } = useParams<{ id: string; commentId: string }>();

  return (
    <div>
      <p>id: {id}</p>
      <p>commentId: {commentId}</p>
    </div>
  );
}
```

- `useParams()` 훅에 필요한 식별자를 타입으로 지정하면, 서버 컴포넌트와 동일하게 여러 세그먼트의 값을 한 번에 받아올 수 있음
- 예: `/post/10/comment/5` 접근 시 `id`는 `"10"`, `commentId`는 `"5"`

## 정리

- 동적 라우트는 **중첩해서 정의**할 수 있으며, 이를 **중첩 동적 라우트**라고 부름
- 같은 트리 안에서 동적 세그먼트 폴더의 **식별자는 항상 고유해야 함** (중복 시 에러)
- 서버 컴포넌트: `params`(Promise) 타입에 필요한 모든 식별자를 명시하고 `await`로 값을 꺼냄
- 클라이언트 컴포넌트: `useParams()` 훅으로 동일하게 여러 세그먼트 값을 받아올 수 있음
- 하위 페이지에서도 상위 세그먼트의 동적 값을 함께 받아올 수 있다는 점이 핵심

이처럼 동적 라우트를 중첩하면 게시글-댓글처럼 계층 구조를 가진 데이터에 대해 훨씬 **유연한 경로**를 정의할 수 있습니다.
