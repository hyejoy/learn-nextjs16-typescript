# URL 구조 살펴보기

라우팅을 배우기 위한 기초로, URL의 세부 구조와 각 부분의 명칭을 정리합니다.

## URL이란?

**URL(Uniform Resource Locator)**: 웹에서 특정 자원의 위치를 나타내는 문자열 주소. 브라우저 주소창에 입력하는 문자열 주소가 곧 URL입니다.

## URL 구조 예시

```
https://www.scoding.kr:443/user/profile?id=123&type=admin#section1
```

## 구성 요소별 명칭

### 1. 프로토콜 (Protocol)

- 예: `https`
- 컴퓨터와 컴퓨터가 통신할 때 지켜야 하는 규칙/약속
- 주로 `http` 또는 `https` 사용
- `://` (콜론 슬래시 슬래시)는 엄밀히는 프로토콜에 포함되지 않고, **프로토콜과 뒤에 오는 주소를 구분하는 표준 구분자**

### 2. 서브 도메인 (Subdomain)

- 예: `www`

### 3. 2차 도메인 (Second-level domain)

- 예: `scoding`

### 4. 최상위 도메인 (TLD, Top-level domain)

- 예: `kr`

### 5. 포트 번호 (Port)

- `:` 뒤에 붙는 숫자
- 예: `443`

### 호스트 (Host)

> 서브 도메인 + 2차 도메인 + 최상위 도메인 + 포트 번호를 모두 포함한 전체

### 도메인 네임 (Domain Name)

> 서브 도메인과 포트 번호를 **제외한** 2차 도메인 + 최상위 도메인

- 예: `scoding.kr`
- 실무에서는 흔히 "도메인"이라고 혼용해서 부름

### 6. 경로 (Path)

- 호스트 다음에 오는 `/`로 시작하는 문자열
- 예: `/user/profile`
- 영어로 **Path**라는 용어도 많이 사용

#### 세그먼트 (Segment)

- 경로에서 `/`로 구분되는 각 부분
- 예: `/user/profile`에서 `user`, `profile`이 각각 하나의 세그먼트

### 7. 쿼리 스트링 (Query String)

- 경로 다음에 `?`로 시작하는 문자열
- `key=value` 형태로 구성
- `&` 기호로 여러 개의 쿼리를 연결
- 예: `?id=123&type=admin`

### 8. 프래그먼트 (Fragment)

- `#` 기호로 시작하는 문자열
- 예: `#section1`
- 페이지 내 **특정 위치를 지정**하는 용도
- 최근 URL 구조에서는 자주 사용되지는 않음

## 전체 구조 한눈에 보기

| 구성 요소                         | 예시                 |
| --------------------------------- | -------------------- |
| 프로토콜                          | `https`              |
| 서브 도메인                       | `www`                |
| 2차 도메인                        | `scoding`            |
| 최상위 도메인                     | `kr`                 |
| 포트 번호                         | `443`                |
| **호스트** (서브+2차+최상위+포트) | `www.scoding.kr:443` |
| **도메인 네임** (2차+최상위)      | `scoding.kr`         |
| 경로 (path)                       | `/user/profile`      |
| 세그먼트                          | `user`, `profile`    |
| 쿼리 스트링                       | `?id=123&type=admin` |
| 프래그먼트                        | `#section1`          |

## 정리

URL은 프로토콜, 호스트(서브 도메인·도메인 네임·포트 번호), 경로(세그먼트), 쿼리 스트링, 프래그먼트로 구성됩니다. 이 명칭들은 앞으로 Next.js의 라우팅을 학습할 때 계속 사용되므로 정확히 이해해두는 것이 중요합니다.
