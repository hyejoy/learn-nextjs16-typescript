# 중첩 라우트 (Nested Routes)

앞서 `About`, `Blog`처럼 세그먼트가 1개인 라우트를 정의해봤다면, 이번에는 **`/about/contact`처럼 세그먼트가 2개 이상인 경로**를 정의하는 방법을 살펴봅니다.

## /about/contact 경로 정의하기

Next.js에서 폴더는 경로를 구성하는 **세그먼트** 역할을 합니다. 따라서 세그먼트가 2개인 경로는 **폴더를 중첩**하여 만듭니다.

```
app/
 └── about/
      └── contact/
           └── page.tsx
```

```tsx
// app/about/contact/page.tsx
export default function Page() {
  return <div>Contact Page</div>;
}
```

### 구조 설명

| 세그먼트                     | 담당 폴더                          |
| ---------------------------- | ---------------------------------- |
| 첫 번째 세그먼트 (`about`)   | `app` 폴더 하위의 `about` 폴더     |
| 두 번째 세그먼트 (`contact`) | `about` 폴더 하위의 `contact` 폴더 |

- `/about/contact` 경로로 접근하면 `about/contact/page.tsx`의 내용이 화면에 표시됨
- 이 컴포넌트 내용 역시 다른 라우트와 마찬가지로 **`layout.tsx`의 `children` 자리에 렌더링**됨

## /blog/first-post 경로 정의하기

같은 방식으로 하나 더 정의해봅니다.

```
app/
 └── blog/
      └── first-post/
           └── page.tsx
```

```tsx
// app/blog/first-post/page.tsx
export default function Page() {
  return <div>First Post Page</div>;
}
```

| 세그먼트                        | 담당 폴더                            |
| ------------------------------- | ------------------------------------ |
| 첫 번째 세그먼트 (`blog`)       | `app` 폴더 하위의 `blog` 폴더        |
| 두 번째 세그먼트 (`first-post`) | `blog` 폴더 하위의 `first-post` 폴더 |

- `/blog/first-post` 경로로 접근하면 `blog/first-post/page.tsx`의 내용이 표시됨
- 마찬가지로 `layout.tsx`의 `children` 자리에 렌더링됨

## 중첩 라우트란?

> Next.js의 App Router에서 **폴더를 중첩하여 라우트를 구성하는 방식**을 **중첩 라우트(Nested Routes)**라고 부릅니다.

### 장점

- 세그먼트가 여러 개인 복잡한 경로라도, **폴더를 계층적으로 만들기만 하면** 직관적이고 명확하게 라우트를 정의할 수 있음
- 폴더 구조 = URL 경로 구조 이므로, 코드만 봐도 라우트 구조를 쉽게 파악 가능

## 정리

```
app/about/contact/page.tsx        →  /about/contact
app/blog/first-post/page.tsx      →  /blog/first-post
```

- 폴더를 계속 중첩하면 세그먼트가 몇 개든 원하는 깊이의 경로를 만들 수 있음
- 각 세그먼트 폴더의 최하위에 위치한 `page.tsx`가 해당 경로의 페이지 콘텐츠를 담당
