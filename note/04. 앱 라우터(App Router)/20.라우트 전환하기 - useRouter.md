# useRouter 훅으로 라우트 전환하기

## Link 컴포넌트와의 차이

- `Link` 컴포넌트: 서버/클라이언트 컴포넌트 **모두**에서 사용 가능한 가장 기본적인 라우트 전환 방식. **정적인 링크 이동**만 가능
- `useRouter` 훅: **클라이언트 컴포넌트 전용**. 이벤트 핸들러 안에서 **동적으로 라우트를 제어**할 때 사용

### 언제 useRouter가 필요한가?

버튼 클릭 시 특정 로직을 먼저 수행하고, 그 로직이 끝난 뒤 라우트를 전환해야 하는 경우:

- `Link` 컴포넌트로는 처리 불가 (정적 이동만 가능)
- 이벤트 핸들러 내부에서 **동적으로** 라우트를 전환해야 하므로 `useRouter` 훅 사용

## 기본 사용법

```tsx
"use client";

import { useRouter } from "next/navigation";

export default function Page() {
  const router = useRouter();

  const handleClick = () => {
    // 어떤 로직 수행 후...
    router.push("/about");
  };

  return <button onClick={handleClick}>이동</button>;
}
```

- `useRouter`는 **`next/navigation`** 패키지에서 import
- 호출하면 **라우터 인스턴스 객체** 반환
- `Link` 컴포넌트와 마찬가지로, 전환 시 전체 리소스를 다시 다운로드하지 않고 **변경된 부분만 자연스럽게 업데이트**

## 라우터 인스턴스의 주요 메서드

### 1. push(path)

- 매개변수로 전달된 경로로 라우트 전환
- `Link` 컴포넌트와 동작 방식이 동일
- **브라우저 히스토리에 기록을 남김** → 뒤로 가기로 이전 페이지로 돌아갈 수 있음

```tsx
router.push("/about");
```

### 2. replace(path)

- `push`와 동일하게 라우트를 전환하지만, **브라우저 히스토리에 기록을 남기지 않음**
- 전환 후 뒤로 가기를 눌러도 **이전 페이지로 돌아가지지 않음** (뒤로 갈 히스토리 자체가 없음)

```tsx
router.replace("/about");
```

> 예: 로그인 후 로그인 페이지로 다시 못 돌아가게 할 때 유용

### 3. back()

- 브라우저의 **뒤로 가기**와 동일
- 뒤로 갈 히스토리가 있을 때만 정상 동작

```tsx
router.back();
```

### 4. forward()

- 브라우저의 **앞으로 가기**와 동일
- 앞으로 갈 히스토리가 있을 때만 정상 동작

```tsx
router.forward();
```

### 5. refresh()

- **현재 라우트의 리소스를 다시 불러옴**
- 서버 컴포넌트에서 데이터를 다시 패칭해야 할 때 유용 (추후 데이터 패칭 학습 시 자세히 다룸)

```tsx
router.refresh();
```

### 6. prefetch(path)

- 지정한 경로의 데이터를 **미리 불러와서** 라우트 전환을 더 빠르고 부드럽게 만듦
- 추후 데이터 패칭 학습 시 자세히 다룸

```tsx
router.prefetch("/about");
```

## push vs replace 비교

| 메서드    | 히스토리 기록 | 뒤로 가기 동작                                              |
| --------- | ------------- | ----------------------------------------------------------- |
| `push`    | 남김          | 이전 페이지로 돌아갈 수 있음                                |
| `replace` | 남기지 않음   | 이전 페이지로 돌아갈 수 없음 (뒤로 갈 히스토리 자체가 없음) |

## 정리

| 메서드     | 용도                             |
| ---------- | -------------------------------- |
| `push`     | 새 경로로 이동 (히스토리 기록 O) |
| `replace`  | 새 경로로 이동 (히스토리 기록 X) |
| `back`     | 뒤로 가기                        |
| `forward`  | 앞으로 가기                      |
| `refresh`  | 현재 라우트 리소스 재요청        |
| `prefetch` | 경로 데이터 미리 불러오기        |

- 우선 **`push`, `replace`, `back`, `forward`**는 기본적으로 알아두고
- **`refresh`, `prefetch`**는 데이터 패칭을 학습할 때 다시 자세히 다룰 예정
- `useRouter` 훅의 가장 큰 장점은 **버튼 클릭, 이벤트 처리, 조건문 등 동적인 로직 안에서 라우트 전환을 제어**할 수 있다는 점
