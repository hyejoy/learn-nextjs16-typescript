# 앱 라우터 기본 개념

## 앱 라우터란?

- 이름 그대로 **`app` 폴더를 기반으로 페이지를 구성**하고 렌더링 흐름을 제어하는 방식
- Next.js는 **폴더 구조와 파일 이름만으로 라우트를 자동 생성**
- 개발자가 별도의 라우팅 설정을 하지 않아도, **파일의 위치와 이름에 따라 자동으로 URL 경로가 생성**됨

## 루트 경로와 app 폴더

- Next.js 프로젝트 실행 시 기본적으로 `localhost:3000`에서 애플리케이션이 열림
- 별도의 하위 경로가 없는 기본 경로를 **루트 경로**라고 부름
- 루트 경로는 프로젝트의 **`app` 폴더**와 연결됨
- 이 경로에서 보여질 화면 내용은 **`page.tsx`** 파일에 작성

## layout.tsx와 page.tsx의 관계

- `page.tsx`: 일반적인 React 컴포넌트처럼 작성 가능. 개별 콘텐츠를 담당
- `layout.tsx`: 상위 구조(레이아웃)를 담당
- `page.tsx`의 내용은 `layout.tsx`의 **`children` 영역**에 자동으로 렌더링됨

### 구조 (개념도)

```
Layout 컴포넌트
 └─ children: Page 컴포넌트
```

- Layout 컴포넌트가 Page 컴포넌트를 **중첩(nesting)**하여 화면에 렌더링되는 형태

## 필수 규칙

앱 라우터는 다음 규칙을 기반으로 동작하며, **개발자가 임의로 변경할 수 없는 파일 시스템 라우팅 규칙**입니다.

1. 각 프로젝트에는 반드시 **하나의 `layout.tsx`와 `page.tsx`**가 있어야 함
2. `layout.tsx`는 여러 개 생성 가능하지만, 그중 **앱 라우터의 최상위 경로에 있는 `layout.tsx`(루트 레이아웃)는 반드시 `<html>`과 `<body>` 태그를 포함**해야 함
3. 최상위 레이아웃이 아니더라도, 모든 `layout.tsx`는 **`children`을 렌더링하는 코드를 반드시 포함**해야 함

## 정리

- 앱 라우터는 `app` 폴더의 구조와 파일명을 기반으로 URL 경로를 자동 생성
- `layout.tsx`(상위 구조) + `page.tsx`(개별 콘텐츠)의 중첩 구조로 렌더링
- 루트 레이아웃은 `html`, `body` 태그 포함 필수, 모든 레이아웃은 `children` 렌더링 코드 포함 필수
