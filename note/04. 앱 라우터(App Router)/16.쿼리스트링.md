# 쿼리 스트링(Query String) 다루기

동적 세그먼트에 이어, URL을 구성하는 또 다른 요소인 **쿼리 스트링**의 값을 가져오는 방법을 살펴봅니다.

## 쿼리 스트링이란?

- URL 뒤에 **`?`**를 사용하여 추가적인 데이터를 전달하는 방식
- 예: `/post1?lang=ko`
  - `lang`: **쿼리 키(query key)**
  - `ko`: **쿼리 값(query value)**

## 준비: 동적 라우트 정의 (복습)

```
app/
 └── post/
      └── [id]/
           └── page.tsx
```

- `/post1`, `/post2`, `/post100`처럼 두 번째 세그먼트가 동적으로 처리됨
- 이 상태에서 `/post1?lang=ko`처럼 쿼리 스트링을 추가해도, 여전히 `/post1` 경로의 페이지가 보여지며 쿼리 스트링은 **추가 데이터**로 전달됨

## 서버 컴포넌트: searchParams props

동적 세그먼트 값을 받을 때 `params`를 썼다면, 쿼리 스트링 값을 받을 때는 **`searchParams`** props를 사용합니다.

```tsx
// app/post/[id]/page.tsx
export default async function Page({
  params,
  searchParams,
}: {
  params: Promise<{ id: string }>;
  searchParams: Promise<{ lang: string }>;
}) {
  const { id } = await params;
  const { lang } = await searchParams;

  return (
    <div>
      <p>id: {id}</p>
      <p>lang: {lang}</p>
    </div>
  );
}
```

- `searchParams`도 `params`와 마찬가지로 **`Promise` 타입**
- 받고자 하는 쿼리 키를 객체 형태로 타입 지정 (예: `{ lang: string }`)
- `await searchParams`로 값을 꺼낸 뒤 구조 분해 할당
- 동적 세그먼트 값(`params`)과 쿼리 스트링 값(`searchParams`)을 **동시에 사용 가능**

## 클라이언트 컴포넌트: useSearchParams 훅

```tsx
"use client";

import { useParams, useSearchParams } from "next/navigation";

export default function PostDetailPage() {
  const searchParams = useSearchParams();
  const lang = searchParams.get("lang");

  const { id } = useParams<{ id: string }>();

  return (
    <div>
      <p>id: {id}</p>
      <p>lang: {lang}</p>
    </div>
  );
}
```

- `useSearchParams()` 훅으로 `searchParams` 객체 생성
- 이 객체의 **`get()` 메서드**에 쿼리 키를 전달하면 해당 값 조회 가능
  - 예: `searchParams.get("lang")` → `"ko"` 또는 `"en"`
- 동적 세그먼트 값은 기존과 동일하게 `useParams()` 훅으로 받아옴

## 서버 vs 클라이언트 비교

| 구분                | 동적 세그먼트      | 쿼리 스트링                             |
| ------------------- | ------------------ | --------------------------------------- |
| 서버 컴포넌트       | `params` (Promise) | `searchParams` (Promise)                |
| 클라이언트 컴포넌트 | `useParams()` 훅   | `useSearchParams()` 훅 + `get()` 메서드 |

## 정리

- 쿼리 스트링은 `?key=value` 형태로 URL에 추가 데이터를 전달하는 방식
- **서버 컴포넌트**: `searchParams` props(Promise 타입)로 값 조회
- **클라이언트 컴포넌트**: `useSearchParams()` 훅 + `get()` 메서드로 값 조회
- 동적 세그먼트(`params`/`useParams`)와 쿼리 스트링(`searchParams`/`useSearchParams`)을 함께 사용하면 URL 기반의 다양한 데이터를 유연하게 다룰 수 있음
