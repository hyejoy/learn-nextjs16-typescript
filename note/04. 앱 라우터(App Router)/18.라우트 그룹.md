# 라우트 그룹 (Route Groups)

## 라우트 그룹이란?

- Next.js App Router가 제공하는, **관련된 라우트 세그먼트 폴더를 하나로 묶어 관리**할 수 있는 기능
- 지정 방법: **소괄호 `( )`**로 된 폴더를 만들고 그 안에 관련 라우트 세그먼트 폴더를 이동
- 소괄호로 된 그룹 폴더는 **라우트 세그먼트로 취급되지 않음** → 순수하게 **논리적인 그룹화** 역할만 함

```
app/
 └── (main)/
      ├── about/
      │    └── page.tsx
      └── blog/
           └── page.tsx
```

- `(main)` 폴더가 있어도 경로는 그대로 `/about`, `/blog`로 접근 가능

## 왜 필요한가?

App Router는 **파일 시스템 기반 라우팅**을 사용하므로, 프로젝트가 커질수록 `app` 폴더 하위에 폴더가 계속 늘어납니다.

- 소규모 프로젝트에서는 문제없지만, 페이지가 많아지면:
  - 폴더가 너무 많아져서 **가독성 저하**
  - 어떤 폴더가 어떤 역할을 하는지 **한눈에 구분하기 어려움**

이럴 때 **라우트 그룹**으로 관련 있는 라우트를 논리적으로 묶어 정리할 수 있습니다.

## 적용 예시

```
app/
 ├── (auth)/
 │    ├── login/
 │    ├── register/
 │    └── forget-password/
 ├── (dashboard)/
 │    ├── analytics/
 │    ├── summary/
 │    └── settings/
 └── (marketing)/
      ├── about/
      └── contact/
```

- `about`은 마케팅으로, `analytics`는 대시보드로, `login`/`register`/`forget-password`는 auth로 이동
- 바탕화면에 폴더를 만들어 관련 파일을 정리하는 것과 같은 개념

## 경로에는 영향 없음

라우트 그룹 폴더는 **경로에서 철저히 무시**됩니다.

- `(auth)/login/page.tsx`가 있어도 `/auth/login`이 아니라 **`/login`**으로 접근
- `(marketing)/about/page.tsx`도 `/about`으로 그대로 접근

## ⚠️ 주의사항 1: 루트 레이아웃 누락 문제

라우트 그룹으로 폴더를 나누더라도, **각 경로는 반드시 루트 레이아웃을 거쳐야** 합니다.

### 문제 상황

```
app/
 └── (auth)/
      ├── layout.tsx   ← 루트 레이아웃이 여기로 이동됨
      ├── login/
      └── register/
 └── (dashboard)/
      └── analytics/    ← 거쳐갈 layout.tsx가 없음!
 └── (marketing)/
      └── about/         ← 거쳐갈 layout.tsx가 없음!
```

- `layout.tsx`(루트 레이아웃)를 실수로 `(auth)` 그룹 폴더 안으로만 이동시키면:
  - `(auth)` 그룹의 경로(`/login`, `/register`)는 문제없이 렌더링됨
  - 하지만 `(dashboard)`, `(marketing)` 그룹의 경로는 **거쳐갈 `layout.tsx`가 없어서 에러 발생**
  - 에러 메시지: HTML과 body 태그가 루트 레이아웃에 존재하지 않는다는 내용

### 해결

- 라우트 그룹으로 폴더를 나누더라도, **모든 경로가 반드시 루트 레이아웃을 거칠 수 있도록** `layout.tsx`의 위치를 신경 써야 함
- 보통 루트 레이아웃은 `app` 폴더 최상위에 그대로 유지하는 것이 안전

## 라우트 그룹의 중첩

라우트 그룹 폴더는 **몇 번이고 중첩 가능**합니다.

```
app/
 └── (admin)/
      └── (dashboard)/
           └── analytics/
 └── (site)/
      ├── (auth)/
      │    └── login/
      └── (marketing)/
           └── about/
```

- 그룹 폴더가 여러 겹으로 중첩되어 있어도, 라우트 그룹은 경로를 구성하는 세그먼트에 **전혀 영향을 미치지 않음**
- `/login`, `/about` 등으로 동일하게 접근 가능

## 정리

| 특징      | 설명                                                                           |
| --------- | ------------------------------------------------------------------------------ |
| 지정 방법 | 폴더명을 `(그룹명)`처럼 소괄호로 감쌈                                          |
| 경로 영향 | 없음 (라우트 세그먼트로 취급되지 않음)                                         |
| 목적      | 관련 라우트를 논리적으로 그룹화하여 가독성 향상                                |
| 중첩      | 여러 겹 중첩 가능                                                              |
| 주의점    | 모든 그룹의 경로가 반드시 루트 레이아웃을 거치도록 `layout.tsx` 위치 관리 필요 |
