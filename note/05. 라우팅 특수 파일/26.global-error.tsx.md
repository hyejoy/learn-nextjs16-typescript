# global-error.tsx (루트 레이아웃 에러 처리)

## 복습: error.tsx의 한계

앞서 배운 `error.tsx`는 **페이지 컴포넌트를 감싸는 Error Boundary**만 형성합니다. 따라서 **루트 레이아웃(`app/layout.tsx`)에서 발생하는 에러는 처리하지 못합니다.**

```tsx
// app/layout.tsx
export default function RootLayout({ children }) {
  throw new Error("루트 레이아웃 에러");
  return (
    <html>
      <body>{children}</body>
    </html>
  );
}
```

- `app/error.tsx`가 있어도 이 에러는 처리되지 않음
- Next.js의 **내장 에러 오버레이**만 표시되고, 대체 UI를 표시할 방법이 없음

## global-error.tsx란?

> `error.tsx`와 완전히 동일한 역할을 하지만, **에러 바운더리 경계를 루트 레이아웃까지 포함한 전체 영역**에서 생성할 수 있게 해주는 특수 파일

```
app/
 ├── layout.tsx
 ├── error.tsx          (페이지 컴포넌트만 감싸는 에러 처리)
 └── global-error.tsx    (루트 레이아웃까지 포함해서 감싸는 에러 처리)
```

## 작성법

```tsx
// app/global-error.tsx
"use client";

export default function GlobalError({
  error,
  reset,
}: {
  error: Error & { digest?: string };
  reset: () => void;
}) {
  return (
    <html>
      <body>
        <title>전역 에러 발생</title>
        <meta name="description" content="앱 전용 오류 페이지" />
        <p>에러 발생: {error.message}</p>
        <button onClick={() => reset()}>다시 시도하기</button>
      </body>
    </html>
  );
}
```

- `error.tsx`와 props(`error`, `reset`) 구조는 **완전히 동일**
- 단, `global-error.tsx`는 **루트 레이아웃 바깥에서 에러 바운더리가 형성**되므로, 루트 레이아웃과 **독립적으로 렌더링**됨

## ⚠️ 필수: html, body 태그 포함

`global-error.tsx`는 루트 레이아웃을 거치지 않으므로, **반드시 `<html>`, `<body>` 태그를 직접 포함**해야 합니다.

## ⚠️ 메타데이터 설정 불가

- 루트 레이아웃에는 보통 메타데이터 설정 코드가 포함되지만, `global-error.tsx`는 **루트 레이아웃을 거치지 않으므로 그 메타데이터 설정을 사용할 수 없음**
- 대신 **React 19에서 추가된 메타데이터 태그**를 직접 사용해야 함

```tsx
<title>전역 에러 발생</title>
<meta name="description" content="앱 전용 오류 페이지" />
```

- `<title>` 태그를 직접 작성하면 브라우저 탭 제목이 실제로 변경됨 (React 19의 메타데이터 태그 지원 기능)
- `<meta>` 태그로 description 등 세부 메타데이터도 직접 지정 가능

## error.tsx vs global-error.tsx 비교

| 구분                    | error.tsx                             | global-error.tsx                               |
| ----------------------- | ------------------------------------- | ---------------------------------------------- |
| 감싸는 범위             | 페이지 컴포넌트만                     | **루트 레이아웃 포함 전체**                    |
| 루트 레이아웃 통과 여부 | 통과함 (children으로 렌더링)          | **통과하지 않음** (독립적으로 렌더링)          |
| html/body 태그          | 불필요                                | **필수로 직접 포함**                           |
| 메타데이터 설정         | 루트 레이아웃의 설정 그대로 사용 가능 | 사용 불가 → React 19 메타데이터 태그 직접 작성 |
| 처리 대상               | 페이지 컴포넌트의 에러                | **루트 레이아웃을 포함한 모든 에러**           |

## 정리

- `error.tsx`: **페이지 컴포넌트**를 감싸는 Error Boundary 경계 형성
- `global-error.tsx`: **루트 레이아웃**을 감싸는 Error Boundary 경계 형성
- `global-error.tsx`를 사용하면 루트 레이아웃에서 발생하는 에러까지 대체 UI로 처리할 수 있지만, 루트 레이아웃을 거치지 않으므로 `html`/`body` 태그를 직접 작성해야 하고 메타데이터도 React 19 태그로 별도 설정해야 함
